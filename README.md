# clon3d-emulationstation-os

A custom fork of [RetroPie EmulationStation](https://github.com/RetroPie/EmulationStation) for the Clon3D project.

EmulationStation is a cross-platform graphical front-end for emulators with controller navigation.

## Upstream

This repository tracks upstream: `https://github.com/RetroPie/EmulationStation`

To sync with upstream changes:
```bash
git fetch upstream
git merge upstream/master
```
